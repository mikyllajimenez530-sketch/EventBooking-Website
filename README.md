# Eventify – Responsive Event Booking Website

Eventify is a **modern, responsive web application** for discovering, booking, and managing events. Users can browse upcoming events, view details, and reserve tickets, while enjoying a clean and professional interface.

---

## 🌟 Features

- **Home Page:** Highlight featured events and categories.
- **Events Page:**  
  - Filter events by category (Music, Tech, Art, Sports)  
  - Search events by name  
  - Slider with left/right arrows for smooth navigation  
- **Event Details & Booking:**  
  - Select an event and view details  
  - Choose number of tickets  
  - Automatic total price calculation  
  - Event image, title, and location dynamically displayed  
- **Contact Page:**  
  - Contact form with validation  
  - Eventify contact info and location map  

---

## 🛠 Technologies Used

- HTML5, CSS3, JavaScript (ES6)  
- Google Fonts (Poppins)  
- Font Awesome icons  
- Responsive design (flexbox + media queries)
